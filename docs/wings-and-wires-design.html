01 · Concept

What this project is about

White storks migrate from Europe to Africa every year. They cross the same geography as thousands of human migrants. But only one of these migrations is fully documented — precise to the meter, precise to the second.

This project places both migrations on the same map. It does not editorialize. It lets the data speak through its density, its gaps, and its silence.

The critical argument comes from the researcher's own fieldwork in Barcelona — a city that brands itself as open, while systematically rendering certain migrations invisible. The project extends this argument from the city to the sea.

02 · Opening Text

The words the user sees first

This text appears before the map. It fades in line by line, then fades out. The map opens underneath it.

The migration of birds is a map. The migration of people is a gap. Both cross the same wind, the same sea, the same pull of the earth. Only one is being watched. Of the others —
we have numbers.
Sometimes not even those.

Animation: each line fades in at 0.8s intervals. After the last line, a 3-second pause. Then the entire text fades out slowly (2s), and the map fades in beneath it.

04 · Chapter One

Mediterranean

Introduction sequence

01
Map opens. One bird.

The map fades in showing Europe and North Africa. A single white stork begins its journey from southern Germany. Its GPS trail grows slowly — not animated at full speed, but at a pace the user can follow. The rest of the map is empty.

D3 path transition Mapbox GL
02
France. Spain. The coast.

The trail moves south through France, into the Iberian Peninsula. The user is following. No text. No explanation. Just the bird and the map. Barcelona is visible on the coastline — no label, but it is there.

Scroll-triggered animation
03
Gibraltar. The bird turns.

The trail reaches the Strait of Gibraltar — 14km of water. The bird does not cross. It turns, follows the land edge. At this exact moment, the sea surface begins to change color — barely perceptible, a darkening. No text appears yet. The user senses something but does not know what.

CSS color transition on SVG layer Opacity: 0 → 0.15
04
Visual pull. User clicks.

The darkened area on the sea pulses very gently — not a blinking indicator, more like breathing. No cursor change, no label. The user is drawn to it. When they click, the camera begins a slow push toward the sea surface.

CSS keyframe pulse · opacity 0.15 → 0.25 → 0.15
05
Time axis appears. User drags.

The map has pushed in to show only the Mediterranean. A minimal time axis appears at the bottom: 2014 — 2026. The sea is still just a dark color, no data points yet. As the user drags the slider forward, the color deepens. The area grows. The user does not yet know what they are accumulating.

D3 range input · color interpolation
06
Slider reaches today. Revelation.

When the slider hits the rightmost position, the color holds for 2 seconds. Then a single number appears in the center of the sea:

23,858

Below it, two lines of text fade in slowly:

This is what we recorded.
The rest, the sea kept.

Then the color dissolves into individual data points — each point one death record. Filled circles have counts. Empty circles are missing data.

D3 force simulation · enter() transition

Data body — four cuts

CUT 01
Scale — the accumulation over time
CHART

A minimal line chart showing monthly death counts from 2014 to 2026. The x-axis is time. The y-axis has no label — just the shape of the data. Peak months are marked with a dot. The chart does not explain itself.

Below the chart: total recorded deaths by route (Western / Central / Eastern Med), shown as three stacked numbers. No bar chart. Just numbers in space.

CUT 02
Density contrast — the same map, two data sets
MAP

The Mediterranean map returns, now showing both data layers simultaneously. Stork GPS points in amber — thousands of them, precise, individual. Human death records in dark red — three approximate points, one per route.

The visual argument is immediate: one data set covers the map like a constellation. The other barely exists.

User can toggle between layers. No animation — just instant switch. The contrast is the content.

CUT 03
Missing data — what the sea kept
CRITICAL CORE

A grid of all 324 death records. Each record is a small square. Squares with data are filled (dark red). Squares without precise coordinates are outlined only — hollow. A label appears: "Location: estimated. Coordinates: not available."

Hovering over any square shows what information exists and what does not. The absence is as visible as the presence.

This is the most critical section of the entire project. The missing data is not a gap in the visualization — it is the visualization.

Your voice — the researcher's perspective

After the data cuts, the map fades slightly. A block of text appears — not academic, not explanatory. A moment from your fieldwork in Barcelona.

Field note · Barcelona · October 2025

I needed to duplicate a set of keys. I walked past three different shops selling beautifully designed keychains. I had to walk four blocks out of the gentrified zone to find an actual locksmith. The city had been redesigned for consumption, not for the people who live here. Some things are made visible. Others are not. The choice is never neutral.

This fragment does not explain the data. It creates a resonance — the logic of selective visibility that you identified in Barcelona is the same logic at work in the Mediterranean data. The user makes the connection themselves.

05 · Transition

Between the two chapters

The map zooms out slowly until both the Mediterranean and the Americas are visible in the same frame. No text. The user sees the scale of what they are about to enter.

A single horizontal line crosses the screen — the equator. Then the camera moves west.

06 · Chapter Two

Americas

The same structure as Chapter One, but different geography and different data.

A Swainson's Hawk begins its migration from North America, moving south. The US-Mexico border appears as a line. The bird crosses it without stopping. Then the human data emerges — CBP encounter data, UNHCR Central American migration figures.

The researcher's voice returns — this time connecting the Americas data to the broader argument: the border is a line that exists for some species and not others. The data gap here is even larger. The political stakes are different but the logic is identical.

Researcher's note · Chapter Two

Bad Bunny performed at the Latin Grammys the same year record numbers of Central Americans were recorded crossing the desert. One image circulated globally. The other was a number in a database. Both were real. Only one was watched.

07 · Ending

The two chapters, side by side

The screen splits. Mediterranean on the left. Americas on the right. Both maps show only the human death data — no birds. The density gaps are visible across both geographies simultaneously.

The opening text returns, this time smaller, quieter, at the bottom of the screen:

The migration of birds is a map.
The migration of people is a gap.
Both cross the same wind, the same sea, the same pull of the earth.
Only one is being watched.

No call to action. No links. The page ends here.

08 · Visual Language

Color, type, motion

Stork GPS trail
Stork position point
Death record (with count)
Death record (no data)
Sea (accumulating)

Typography

Display / Poetic text: Cormorant Garamond, italic, light weight. Used for opening text, chapter headings, voice blocks, and the revelation moment.

Data / Interface text: DM Mono, regular weight. Used for labels, counts, axis values, and technical annotations.

Nothing else. Two fonts only.

Motion principles

All animations are slow. The bird trail grows at walking pace, not flight speed. Data points appear with a fade, not a pop. The camera moves like breath — unhurried. The only moment of stillness is the revelation: 23,858 appears with no animation. It simply exists.

Map style

Dark basemap. No labels except coastlines. Country borders are visible but thin — present, but not the point. The sea is the canvas, not the background.

10 · Tech Stack

How it will be built

Mapbox GL JS
Base map, camera animation, layer management. Dark custom style.
D3.js
Data binding, path transitions, time axis, density visualization, chart cuts.
p5.js
Bird trail animation, particle effects, the sea color accumulation layer.
Python
Data processing scripts (already written). Outputs GeoJSON for D3.
Vercel
Deployment. Single-page static site. No backend needed.
Vanilla JS
Scroll detection, interaction logic, animation orchestration. No framework.
